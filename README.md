# Space Tourism – Multi-Page Website

My solution to the [Space tourism multi-page website challenge](https://www.frontendmentor.io/challenges/space-tourism-multipage-website-gRWj1URZ3) on Frontend Mentor.

> 🚧 Work in progress

## Overview

A responsive multi-page website for a fictional space travel agency with four pages: Home, Destination, Crew and Technology.

Users should be able to:

- View the optimal layout for each page depending on their device's screen size
- See hover and focus states for all interactive elements
- Navigate between the pages and switch between tabs to see new information

## Built with

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) v4
- Mobile-first workflow
- Semantic HTML and accessibility (ARIA)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## What I learned

- Building a design system with Tailwind v4 (`@theme`, custom `@utility` classes)
- Loading Google Fonts with `next/font` and CSS variables
- Server vs. Client Components in the Next.js App Router
- Typing component props and data with TypeScript
- Accessible navigation patterns (`aria-expanded`, `aria-current`, labelled icon buttons)
